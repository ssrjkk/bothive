Три рубежа защиты песочницы:

            
1. Save-Time AST & Regex Guard: API отклоняет скрипты с катастрофическими регулярками (ReDoS) и попытками побега из песочницы еще до сохранения в БД (и при импорте бэкапа).

            
2. Redirect-Hop SSRF Defense: fetch внутри скрипта проверяет каждый редирект и блокирует приватные/loopback IP + DNS rebinding.

            
3. Crypto Safety Caps: ордера ограничены maxOrderValueUsdt (default 100 USDT), суточный maxDailyOrderValueUsdt по умолчанию 0 (выключен — задайте перед live), режим tradeMode: "dry" по умолчанию.

            Никаких «черных ящиков». BotHive поднимает преднастроенные Prometheus (:9090) и Grafana (:3001) вместе с 22 правилами алертинга в prometheus/rules/bothive.yml. Распределенный трейсинг задач BullMQ через OpenTelemetry включается профилем tracing.
          

          

            
Что контролируют 22 правила алертинга:

            
• API SLO burn-rate, p95 latency & high error rate

            
• Worker down, heap growth, reconnect thrashing & VM leaks

            
• Queue wait spikes, stuck failed jobs & DLQ backlog

            
• Unhealthy bots/proxies & crypto order anomalies
